## 6. Update ID 規則

Snapshot L；首有效事件須 U≤L+1≤u。未套用前 u≤L 為 STALE_BEFORE_SNAPSHOT/SKIP；bridge 不符為 FIRST_EVENT_BRIDGE_FAILURE/STOP。後續 u≤local 為 STALE_OR_DUPLICATE/SKIP；U>local+1 為 UPDATE_ID_GAP/STOP。有效 U=local+1 為 CONTIGUOUS，U<local+1≤u 為 OVERLAPPING_CONTIGUOUS。APPLY 後 local=u。STOP 後實例進入 terminal，拒絕續用；不修補或猜測。
