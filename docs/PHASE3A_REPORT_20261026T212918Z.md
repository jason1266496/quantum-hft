## Kernel Subset 與 Test Seal

Train最多1000、Validation/Test最多500；按event time穩定排序，用floor(i*(N-1)/(k-1)) evenly-spaced positions，包含頭尾，不shuffle或看class選樣。Train/Validation subset先固定；Test positions只由已封存row count固定，直到全部selection seals完成後才讀Test資料並保存IDs／class distribution。每split保留selected sample_ids、event range、indices SHA與subset SHA。Phase4 Quantum Kernel/QSVC應沿用同membership及Train scaler universe，才能與RBF公平比較。
- 100ms subset：{"Test": 500, "Train": 1000, "Validation": 500}。
- 1000ms subset：{"Test": 500, "Train": 1000, "Validation": 500}。

Test seal：全部8份selection_manifest.json在任何Test label read前封存並計算SHA；各檔test_evaluated=false的選擇時狀態保留不改。Global barrier SHA連結selection seals；Test結果另存test_evaluation_manifest.json，每model metric_evaluation_count=1。Test prediction warm-up 1次＋正式3次只作timing，三次prediction相同；metrics僅計算一次，沒有Test retuning。Dataset access log記錄兩個horizon Test labels讀取皆在barrier之後。
Final Holdout：LOCKED，FINAL_HOLDOUT_NOT_EVALUATED。僅存在、header/schema、row count、checksum檢查；沒有Holdout feature/label值解析、transform、class distribution、score或diagnostics。
