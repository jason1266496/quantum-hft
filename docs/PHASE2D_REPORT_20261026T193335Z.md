## 2. Schema、時間與算式

四個 horizon：100、200、500、1000ms；每個 horizon 各有獨立 CSV。唯一排序/配對時間為 event_time_ms；每個 source_id/session_id/view 獨立處理。
target = 同 Session 第一筆 event_time_ms >= current_event_time_ms + H；actual_horizon_ms = target_time - current_time；match_error_ms = actual - H。
future_return_bps = (future_mid_price / current_mid_price - 1) * 10000；僅使用 Decimal，precision 50、ROUND_HALF_EVEN。找不到 target 時 invalid_reason=SESSION_TAIL_INSUFFICIENT，無效價格或 feature 另列原因。
match error 大小不會在本階段刪除 RAW_MATCHED；max_match_error_ms 與 gap_threshold_ms 仍為 null。
相同 timestamp 保留原記錄順序；event time 倒退將單調區段切開，禁止跨區段配對並標為無效。
