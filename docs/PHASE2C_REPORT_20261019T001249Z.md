## 7. 全部公式與有效性

```text
mid_price = (best_bid + best_ask) / 2
spread = best_ask - best_bid
spread_bps = spread / mid_price * 10000
bid_volume_k = sum(bid_quantity_i, i=1..k)
ask_volume_k = sum(ask_quantity_i, i=1..k)
obi_k = (bid_volume_k - ask_volume_k) / (bid_volume_k + ask_volume_k), k=1,3,5
cumulative_bid_quantity_i = sum(bid_quantity_j, j=1..i), i=1..5
cumulative_ask_quantity_i = sum(ask_quantity_j, j=1..i), i=1..5
level_imbalance_i = (bid_quantity_i - ask_quantity_i) / (bid_quantity_i + ask_quantity_i)
bid_distance_bps_i = (mid_price - bid_price_i) / mid_price * 10000
ask_distance_bps_i = (ask_price_i - mid_price) / mid_price * 10000
microprice = (best_ask*bid_quantity_1 + best_bid*ask_quantity_1) / (bid_quantity_1 + ask_quantity_1)
microprice_deviation_bps = (microprice - mid_price) / mid_price * 10000
```

price/mid>0、quantity>=0、spread>0、best_bid<best_ask；OBI及level imbalance在[-1,1]，microprice在最佳bid/ask內。OBI分母0留null、ZERO_DEPTH_DENOMINATOR及invalid；單層分母0留null與品質warning，不能硬填0。少於五檔為INSUFFICIENT_TOP5_DEPTH。invalid列保留。
