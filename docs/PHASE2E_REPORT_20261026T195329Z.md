## Embargo、Scaler 與 Walk-forward

embargo_ms=0，NO_ADDITIONAL_EMBARGO_BEYOND_PURGING。現有 Feature 沒有 rolling lookback，actual-target purge 已處理跨 split 標籤視窗；同 split 內 label 仍高度重疊，後續評估不可假設獨立。
Scaler 尚未 fit；只可 Train fit，Validation/Test/Holdout transform；每個 View 獨立、參數需版本化，禁止全資料統計、不同 split 各自fit；event time、ID與categorical metadata不得作數值標準化。
Walk-forward 為 expanding-window 規格；Aggregate 用完整早期 Session，Depth 用同 Session 內時間區段。每個 fold 都從自己的 Train 重新選 match policy並purge train/validation endpoint；沒有使用較晚 formal Train 的政策污染早期 fold。所有 window 都早於 formal Test 和 Holdout。
- aggregate：2 個 window；train/validation時間、counts、每horizon purge及fold policy均存於對應 walk_forward_windows.json。
- depth：2 個 window；train/validation時間、counts、每horizon purge及fold policy均存於對應 walk_forward_windows.json。
