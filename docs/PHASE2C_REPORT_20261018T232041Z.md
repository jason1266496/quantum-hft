## 7. 所有公式

正式計算於 formulas.aggregate / depth；獨立參考位於 reference.reference_features，未呼叫主要公式或Builder。令 pᵇᵢ、qᵇᵢ／pᵃᵢ、qᵃᵢ 為目前第i檔買／賣價量：

```text
mid = (best_bid + best_ask) / 2
spread = best_ask - best_bid
spread_bps = spread / mid * 10000
B_k = sum(q_bid_i, i=1..k); A_k = sum(q_ask_i, i=1..k)
obi_k = (B_k - A_k) / (B_k + A_k), k=1,3,5
cumulative_bid_quantity_i = sum(q_bid_j, j=1..i)
cumulative_ask_quantity_i = sum(q_ask_j, j=1..i)
level_imbalance_i = (q_bid_i - q_ask_i) / (q_bid_i + q_ask_i)
bid_distance_bps_i = (mid - p_bid_i) / mid * 10000
ask_distance_bps_i = (p_ask_i - mid) / mid * 10000
microprice = (best_ask*q_bid_1 + best_bid*q_ask_1) / (q_bid_1+q_ask_1)
microprice_deviation_bps = (microprice-mid) / mid * 10000
```

價格與mid須>0，spread>0，best_bid<best_ask，quantity>=0，OBI及level imbalance∈[-1,1]，microprice在最佳bid/ask內。OBI分母0：null＋ZERO_DEPTH_DENOMINATOR且invalid；單一level分母0：該欄null＋品質warning，其他invalid條件仍獨立判斷，絕不硬編碼為0。
